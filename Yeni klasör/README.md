# Minnoş Checker Final

Roblox hesap kontrol aracı - Modern GUI versiyonu

## Özellikler
- ✔️ Manuel ve dosyadan hesap girişi
- ✔️ Proxy desteği
- ✔️ Thread tabanlı performans
- ✔️ Otomatik ChromeDriver yükleme
- ✔️ Renk kodlu log sistemi
- ✔️ Sadece geçerli hesapları kaydetme

## Kurulum
```bash
pip install -r requirements.txt
```

## Gereksinimler
- Python 3.8+
- Chrome tarayıcı

## Kullanım
1. `MinnoşChecker_Final.py` dosyasını çalıştırın
2. Giriş sekmesini seçin:
   - **Dosya**: `kullanıcı:şifre` formatında txt dosyası
   - **Manuel**: Tek hesap girişi
3. Proxy eklemek isterseniz `proxy.txt` seçin
4. BAŞLAT butonuna basın
